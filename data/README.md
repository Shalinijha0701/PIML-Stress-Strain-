# Experimental data

This directory contains original experimental source files for the two LPBF
alloys used in the project. Files are provided unchanged from the project data
archive; use copies for preprocessing and preserve these sources.

## Ti-6Al-4V

- **Dataset:** Processing, microstructure, mechanical property dataset for
  laser powder bed fusion additively manufactured Ti-6Al-4V
- **Authors:** Qixiang Luo, L. Yin, T. W. Simpson, and A. M. Beese
- **Source:** [Zenodo record 6587905](https://zenodo.org/records/6587905)
- **DOI:** [10.1016/j.addma.2022.102915](https://doi.org/10.1016/j.addma.2022.102915)
- **License:** [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/)
- **Included:** PSP feature table, mechanical-property table, and original
  stress-strain curve archive and curve workbooks.

## AlSi10Mg

- **Dataset:** Processing, microstructure, and mechanical property dataset for
  AlSi10Mg fabricated by laser powder bed fusion additive manufacturing
- **Authors:** Qixiang Luo et al.
- **Source:** [Zenodo record 10008435](https://zenodo.org/records/10008435)
- **DOI:** [10.1016/j.addma.2023.103804](https://doi.org/10.1016/j.addma.2023.103804)
- **License:** [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/)
- **Included:** PSP feature table, mechanical-property table, and original
  stress-strain curve archive and curve workbooks.

The AlSi10Mg curves cover 178 specimens across three groups (60, 58, and 60);
the Ti-6Al-4V dataset covers 168 curves across 42 processing conditions.
Consult the source records and accompanying workbooks for full variable
definitions, units, and experimental details.

`SHA256SUMS.txt` records checksums for the included data files. The dataset
providers retain attribution; cite the records and related publications when
using these data. No preprocessing has been applied here.

# Analysis scripts

Run scripts from the repository root so relative paths resolve consistently.
The script files are placeholders; their analytical workflows have not been
implemented yet.

Planned responsibilities:

- `analysis.py` — primary analysis workflow;
- `replicate_floor.py` — replicate/floor analysis;
- `stats2.py` — supplementary statistical analysis;
- `figures.py` — generate figures from saved results;
- `tables.py` — generate tables from saved results.

Document inputs, output locations, and any random seeds in each script when
implementing it.
